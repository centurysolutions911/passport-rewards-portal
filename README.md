# Passport Rewards client portal (mockup)

Clickable mockup of the Century Solutions client portal for Passport Rewards. All figures are sample data.

Plain static HTML, so there's no build step. `index.html` is the sign-in page; any email takes you into the demo (Overview is `overview.html`).

## Deploy on Vercel
1. Import this repo in Vercel (Add New → Project).
2. Framework preset: **Other**. Leave the build command and output directory empty.
3. Click Deploy.

`vercel.json` hides the site from search engines (noindex).
